# Data Dictionary

## Features

| Feature | Type | Description |
|---------|------|-------------|
| Age | Numeric | Person's age in years |
| Height | Numeric | Height in meters |
| Weight | Numeric | Weight in kilograms |
| Bmi | Numeric | Calculated BMI (Weight / Height²) |

## Target Variable

| Feature | Type | Description |
|---------|------|-------------|
| BmiClass | Categorical | BMI classification category |
| EncodedBmiClass | Numeric | Label encoded version of BmiClass |

## BMI Class Labels

- 0: Normal Weight
- 1: Obese Class 1
- 2: Obese Class 2
- 3: Obese Class 3
- 4: Overweight
- 5: Underweight
